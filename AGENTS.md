# AGENTS.md

## What it is
A Chrome extension (Vite + `@crxjs/vite-plugin`, TypeScript, MV3) that shows Zendrop product cost on Minea product pages using the Zendrop session already in the browser. README.md covers behavior and limits; `Minea_Zendrop_Cost_Finder_Extension_Spec.md` has the MVP design notes.

## Setup and commands
- `npm install`
- `npm run dev`: Vite, rebuilds into `dist/`
- `npm run build`: `tsc --noEmit && vite build`; load `dist/` via `chrome://extensions` > Developer mode > Load unpacked
- `npm test`: `vitest run` (`npm run test:watch` to watch; happy-dom for DOM tests)
- Reload the extension in Chrome after each rebuild.

## Where things live
- `src/content`: detects the Minea product and renders the card
- `src/background`: calls the Zendrop API with the browser session
- `src/popup`: toolbar summary
- `src/shared`: parsing, ranking, product URLs
- `tests/`: parser, matcher, extractor, mount, urls, utils
- `manifest.json`: extension manifest. `icons/` is generated by `scripts/generate-icons.py`.

## Gotchas
- No token or Bearer header: the background worker uses `credentials: "include"`. Do not add stored tokens or the `cookies` permission.
- `.env*` (except `.env.example`) and `productpageminea.html` are gitignored.
- No CI workflows in this repo.
